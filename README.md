# 单词 PK（考研识意对战）

两人固定局：扇贝熟练度 + 错词记忆 + 手机网页对战。  
**部署到云端后，电脑可以关机**，两人手机随时打开固定网址就能玩。

## 最快上手（推荐）

1. 用下面「云端部署」把程序放到免费云上  
2. 得到固定网址，例如 `https://word-pk.onrender.com`  
3. 两人手机打开这个网址，各注册一次  
4. 扇贝同步：优先用「账号密码」；若失败再用 Cookie  
5. 一方点「发起对战」→ 另一方点「加入对战」→ 双方「准备好了」→ 开赛  

**不需要同一 Wi-Fi，不需要一直开着电脑。**

---

## 云端部署（只需做一次，之后不用开电脑）

### 方式一：Render（免费，手机也能操作）

1. 手机浏览器打开 https://render.com 注册（可用 GitHub）  
2. 打开 https://github.com/new 建一个空仓库，例如 `word-pk`  
3. 把本项目文件夹内容上传到该仓库（电脑传一次最快；手机可用 GitHub App 传）  
4. Render → New → Web Service → 选这个仓库  
5. 环境选 Docker，保存。等它部署完  
6. 拿到网址，发给对方，两人收藏

> 免费版闲置会休眠，第一次打开可能要等 30 秒。日常两人玩够用。  
> 免费版重部署可能丢本地数据库，重要进度建议之后再迁到付费小实例或外置数据库。

### 方式二：本地一键（仅调试，要开电脑）

- `启动.bat`：http://127.0.0.1:8765  
- `启动-手机异地.bat`：临时公网链接（链接每次会变）

## 扇贝同步（手机上怎么做）

### 账号密码（省事）

在「扇贝同步」里选「账号密码」，填扇贝手机号/用户名和密码。  
若提示风控/验证码，就改用 Cookie。

### Cookie（更稳）

1. 电脑浏览器登录 https://web.shanbay.com  
2. F12 → Application → Cookies → web.shanbay.com  
3. 复制含 `sessionid` 的整段  
4. 手机上粘贴到「Cookie」方式里  

手机浏览器一般不方便复制 Cookie，所以优先账号密码；失败再找电脑复制一次。
