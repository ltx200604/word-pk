# 单词 PK — 本机电脑方案

程序跑在**你的电脑**上。手机通过公网链接访问，两人异地也能玩。

**注意：** PK 时电脑要保持开机（窗口最小化即可）。关机 = 手机打不开。

---

## 怎么开始

双击：

**`启动-手机异地.bat`**

等窗口里出现一行网址，类似：

```
https://abcd-efgh-ijkl.trycloudflare.com
```

把这个 **https 链接**发给对方。两人手机浏览器打开，收藏即可。

> 链接每次重启会变，变了重新发一次。  
> 电脑本地调试可用 `启动.bat`（只有电脑能开）。

---

## 第一次使用

1. 两人手机打开上面的网址  
2. 各注册一个用户名（只做一次，之后会记住）  
3. 扇贝同步：  
   - 优先「账号密码」登录  
   - 失败再用 Cookie（电脑浏览器登录 web 扇贝 → F12 复制）  
4. 一方点 **发起对战**  
5. 另一方打开页面 → 点 **加入对战**  
6. 双方点 **我准备好了** → 自动开赛  

不用填房间号。

---

## 玩法

- 识意为主：选择题 / 输入中文意思（可混合）  
- 题量可自定义  
- 按双方扇贝熟练度 + 上次错词选题  
- 下一局约一半会复现错词  

---

## 出问题了

| 现象 | 处理 |
|------|------|
| 手机打不开网址 | 看 `启动-手机异地.bat` 窗口是否还在；电脑是否休眠 |
| 链接变了 | 重新复制窗口里新的 trycloudflare 链接 |
| 想先本地试 | 双击 `启动.bat`，浏览器开 http://127.0.0.1:8765 |
| 扇贝同步失败 | 换 Cookie 方式；或重新登录后再同步 |
